# UI Automation Rules

1. Test the real built WPF application.
2. Prefer semantic UI Automation selectors over screen coordinates.
3. Re-resolve controls before interaction.
4. Wait for expected state transitions.
5. Capture a screenshot after important actions.
6. Verify backend/database state for persisted workflows.
7. Record failures with logs and screenshots.
8. Never fabricate a PASS.
9. Never use physical-hardware claims when only simulation was tested.
